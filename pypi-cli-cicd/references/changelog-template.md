# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## IMPORTANT for the release pipeline

The publish workflow extracts release notes by matching a heading of the form:

    ## [X.Y.Z] - YYYY-MM-DD

Keep that exact shape (square brackets around the version). At release time, the
`## [Unreleased]` heading is renamed to `## [X.Y.Z] - <today>`, and a fresh empty
`## [Unreleased]` is added back at the top.
